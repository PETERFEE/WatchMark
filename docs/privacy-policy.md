# WatchMark Privacy Policy

_Last updated: August 21, 2026_

WatchMark lets users select one element on a webpage and receive an alert when that element's text changes. This policy explains what information WatchMark handles and why.

## Information stored by WatchMark

WatchMark stores the following information in Chrome's local extension storage:

- The alert email address entered by the user
- The URL of the webpage selected for monitoring
- A CSS path identifying the selected webpage element
- The last text value observed for that element
- The user's selected refresh interval
- The monitoring and tutorial settings

This information is used only to provide webpage monitoring and alerts. The URL and selected element data allow WatchMark to reconnect after a page refresh.

## Information sent to EmailJS

When the monitored element's text changes and the user has saved an alert email address, WatchMark sends the saved email address and the new text value to the configured EmailJS email-delivery service. This request is made only to deliver the alert requested by the user.

EmailJS may process this information according to its own privacy policy and the production EmailJS account configuration. Before publishing WatchMark, the publisher must replace the development EmailJS identifiers in the extension with production-owned settings.

## Webpage access

WatchMark accesses webpages so the user can choose and monitor one element. It does not automatically collect every page the user visits. The extension reads the selected element's text and stores the selected page URL, CSS path, and last observed value for the monitoring feature.

## Notifications

Chrome desktop notifications and the on-page change alert are generated by the extension. WatchMark does not use this information for advertising, profiling, credit decisions, or unrelated purposes.

## Data sharing and sale

WatchMark does not sell personal information. WatchMark does not share information with third parties except for the EmailJS service request needed to deliver an alert email requested by the user.

## Data retention and deletion

Monitoring data remains in Chrome's local extension storage until the user stops monitoring, clears the extension data, or uninstalls WatchMark. Stopping monitoring removes the monitored URL, selected element path, last observed value, and monitoring state. The saved alert email can be replaced or removed by the user.

## Children's privacy

WatchMark is a general-purpose productivity extension and is not directed specifically to children.

## Changes to this policy

This policy may be updated when WatchMark's data practices or functionality change. The date at the top of this page identifies the latest revision.
